Listas Simplesmente Encadeadas

Estrutura composta por nós, em que cada nó guarda um dado e uma referência para o próximo elemento.

Conceito

Uma Lista Simplesmente Encadeada é uma estrutura formada por nós. Cada nó guarda duas informações: o dado armazenado e a referência para o próximo nó.

Diferente de um vetor, a lista encadeada não precisa ocupar posições consecutivas na memória. Os elementos ficam conectados por referências.

Ela facilita inserções e remoções, mas não permite acesso direto por índice. Para encontrar um valor, normalmente é preciso percorrer a lista a partir do início.

10 → 25 → 40 → null

Exemplo em C#

public class No
{
    public int Valor;
    public No? Proximo;

    public No(int valor)
    {
        Valor = valor;
        Proximo = null;
    }
}

public class ListaSimples
{
    private No? inicio;

    public void InserirNoInicio(int valor)
    {
        No novo = new No(valor);
        novo.Proximo = inicio;
        inicio = novo;
    }

    public void Exibir()
    {
        No? atual = inicio;

        while (atual != null)
        {
            Console.WriteLine(atual.Valor);
            atual = atual.Proximo;
        }
    }
}

Vantagens e cuidados

  • Inserção no início é simples e rápida.
  • O tamanho pode crescer dinamicamente.
  • O acesso não é direto por índice.
  • A navegação ocorre apenas para frente.
