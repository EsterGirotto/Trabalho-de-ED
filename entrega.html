Análise da entrega

O que o trabalho pede

Resumo dos requisitos do Trabalho Prático 2 para orientar a construção do sistema web.

Tema obrigatório

O sistema deve funcionar como um ambiente de ensino de Estruturas de Dados, explicando o conceito geral, a importância do tema e onde essas estruturas são usadas.

Conteúdos da etapa

A primeira etapa precisa abordar TAD, Listas Simplesmente Encadeadas e Listas Duplamente Encadeadas com textos, recursos visuais e exemplos em C#.

Tecnologias indicadas

O front-end pode ser feito livremente. O sistema final deve usar PHP no back-end e banco de dados relacional MySQL.

Itens de entrega

Devem ser entregues o projeto da aplicação web, o manual de instalação e o link do repositório no GitHub.
