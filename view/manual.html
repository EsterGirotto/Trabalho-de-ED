Configuração

Manual de instalação e navegação

Orientações para executar a aplicação localmente e consultar os principais conteúdos do ambiente.

Manual sugerido

  1. Instalar um servidor local, como XAMPP, WAMP ou Laragon.
  2. Copiar a pasta do projeto para o diretório do servidor, por exemplo, htdocs.
  3. Criar um banco de dados MySQL para a aplicação.
  4. Configurar usuário, senha, host e nome do banco no arquivo PHP de conexão.
  5. Abrir o navegador e acessar o endereço local do projeto.
