Listas Duplamente Encadeadas

Estrutura em que cada nó aponta para o próximo e para o anterior, permitindo navegação nos dois sentidos.

Conceito

A Lista Duplamente Encadeada também é formada por nós, mas cada nó possui duas referências: uma para o próximo nó e outra para o nó anterior.

Essa estrutura permite percorrer os dados do início para o fim e do fim para o início. Isso é útil em históricos, editores, players e sistemas com botões de avançar e voltar.

A desvantagem é o uso maior de memória e a necessidade de atualizar corretamente os dois lados da ligação durante inserções e remoções.

null ↔ 8 ↔ 16 ↔ 32 ↔ null

Exemplo em C#

public class NoDuplo
{
    public int Valor;
    public NoDuplo? Anterior;
    public NoDuplo? Proximo;

    public NoDuplo(int valor)
    {
        Valor = valor;
    }
}

public class ListaDupla
{
    private NoDuplo? inicio;
    private NoDuplo? fim;

    public void InserirNoFim(int valor)
    {
        NoDuplo novo = new NoDuplo(valor);

        if (inicio == null)
        {
            inicio = novo;
            fim = novo;
            return;
        }

        fim!.Proximo = novo;
        novo.Anterior = fim;
        fim = novo;
    }
}
