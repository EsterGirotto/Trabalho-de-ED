# Trabalho-de-ED

Ambiente de estudo sobre Estruturas de Dados, com conteudos sobre TAD,
lista simplesmente encadeada e lista duplamente encadeada.

## Como executar

1. Inicie Apache e MySQL no XAMPP.
2. Importe `database/estruturas_dados.sql` no phpMyAdmin.
3. Confira a conexao em `php/conexao.php` se seu MySQL tiver senha.
4. Acesse `http://localhost/Trabalho-de-ED/view/index.html`.

Usuario de teste: `demo@institucional.com` com senha `demo123`.

## Recursos

- Cadastro e login com PHP/MySQL.
- Perfil do estudante com foto, dados pessoais e alteracao de senha.
- Bloqueio das telas de estudo para visitantes sem login.
- Registro de progresso por topico.
- Area de estudos separada com dashboard, trilha, cronometro, quiz, anotacoes e revisao.
- Dados da area de estudos salvos no navegador com localStorage, sem alterar o banco.
- Simuladores visuais para lista simples e lista dupla.
- Exemplos em C# e materiais de apoio.
