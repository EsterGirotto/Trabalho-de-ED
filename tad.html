TAD - Tipo Abstrato de Dados

Um TAD define quais operações podem ser feitas com um conjunto de dados, escondendo detalhes internos da implementação.

Conceito

TAD significa Tipo Abstrato de Dados. Ele representa uma forma de definir um conjunto de dados e as operações permitidas sobre esses dados.

A ideia principal é separar o que uma estrutura faz de como ela faz. Quem usa uma pilha, fila ou lista precisa conhecer suas operações, mas não precisa acessar diretamente sua organização interna.

Esse conceito melhora a organização do programa, cria um contrato de uso, facilita manutenção e permite trocar a implementação interna sem alterar todas as partes do sistema.

Exemplo em C#

public class Pilha
{
    private int[] dados = new int[10];
    private int topo = -1;

    public void Empilhar(int valor)
    {
        if (topo == dados.Length - 1)
            throw new InvalidOperationException("Pilha cheia");

        topo++;
        dados[topo] = valor;
    }

    public int Desempilhar()
    {
        if (topo == -1)
            throw new InvalidOperationException("Pilha vazia");

        int valor = dados[topo];
        topo--;
        return valor;
    }
}

Nesse exemplo, a classe Pilha funciona como um TAD. O usuário chama Empilhar e Desempilhar, mas não manipula diretamente o vetor interno.

Ideia central

O TAD protege os detalhes internos e oferece operações bem definidas.
